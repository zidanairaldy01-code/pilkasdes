🗳️ Test Simulasi Pemilihan

📋 Panduan Testing:

Dokumen ini berisi checklist untuk menguji fitur Simulasi Pemilihan yang baru ditambahkan. Gunakan checklist di bawah untuk memastikan semua fungsi berjalan dengan baik.

1️⃣ Visual & Layout Check

  • Tombol "🗳️ Simulasi Pemilihan" terlihat di modal Visi & Misi
  • Tombol memiliki warna gradient gold yang menarik
  • Progress bar terlihat di bagian atas modal simulasi
  • Progress bar menampilkan persentase (0%, 20%, 40%, 60%, 80%, 100%)
  • Progress bar menampilkan step (Langkah X dari 5)
  • Semua 5 langkah simulasi memiliki ikon yang sesuai
✅ Progress Bar Demo:

Langkah 3 dari 5 - 60%

2️⃣ Functionality Check

  • Klik kandidat utama → Modal Visi & Misi terbuka
  • Klik tombol "🗳️ Simulasi Pemilihan" → Modal simulasi terbuka
  • Step 1: Form NIK dan Token dapat diisi
  • Step 1: Validasi NIK (harus 16 digit) berfungsi
  • Step 1: Validasi Token berfungsi
  • Step 2: Dapat memilih kandidat (01, 02, atau 03)
  • Step 2: Visual checkbox berubah saat kandidat dipilih
  • Step 3: Data konfirmasi (NIK, Token, Kandidat) tampil dengan benar
  • Step 4: Loading animation muncul (2 detik)
  • Step 5: Bukti voting dengan nomor transaksi & waktu muncul
  • Progress bar bergerak dari 0% → 100% sesuai step
  • Tombol "Kembali" berfungsi di step 2 dan 3
  • Tombol "Coba Lagi" mereset simulasi ke step 1
  • Tombol "Selesai" menutup modal simulasi
  • Tombol X (close) menutup modal simulasi
  • Klik overlay (luar modal) menutup modal simulasi

3️⃣ Mobile Responsive Check

  • Modal simulasi tampil baik di layar smartphone (360px - 480px)
  • Grid kandidat berubah dari 3 kolom → 1 kolom di mobile
  • Progress bar tetap mudah dibaca di mobile
  • Form input (NIK & Token) nyaman digunakan di mobile
  • Tombol navigasi (Kembali, Lanjut) tidak overlap di mobile
  • Modal dapat di-scroll dengan lancar di mobile
  • Ukuran font tetap terbaca dengan jelas di mobile
  • Touch target minimal 44x44px (tombol mudah diklik)
📱 Cara Test Mobile:
  1. Buka DevTools (F12)
  2. Aktifkan Device Toolbar (Ctrl+Shift+M)
  3. Pilih device: iPhone SE, Samsung Galaxy S8+, dll.
  4. Test semua fungsi dalam mode mobile

4️⃣ Progress Bar Animation Check

  • Step 1 → Progress bar: 0% (awal)
  • Step 2 → Progress bar: 20% (pilih kandidat)
  • Step 3 → Progress bar: 40% (konfirmasi)
  • Step 4 → Progress bar: 60% (processing)
  • Step 5 → Progress bar: 100% (selesai)
  • Animasi fill progress bar smooth (transition 0.4s)
  • Warna gradient (biru → gold) terlihat dengan baik
🎯 Expected Behavior:

Progress bar harus bergerak secara smooth dan menampilkan persentase yang tepat di setiap langkah. Tidak boleh melompat atau stuck di satu posisi.

5️⃣ Data & Validation Check

  • NIK harus tepat 16 karakter (contoh: 3201234567890123)
  • Token minimal 3 karakter (contoh: ABC123XYZ)
  • Tidak bisa lanjut ke step 2 tanpa isi NIK & Token
  • Alert muncul jika validasi gagal
  • Data NIK & Token muncul di Step 3 (Konfirmasi)
  • Kandidat terpilih muncul di Step 3 dengan badge yang benar
  • Nomor transaksi unik setiap kali submit (format: VOTE-2026-XXXXXXXX)
  • Waktu voting sesuai waktu saat ini (format: DD MMM YYYY, HH:MM WIB)

6️⃣ Browser Compatibility

  • Chrome / Edge (Chromium) - Desktop & Mobile
  • Firefox - Desktop & Mobile
  • Safari - iOS & macOS
  • Samsung Internet
  • UC Browser
⚠️ Catatan:

Pastikan fitur berfungsi di browser yang umum digunakan warga, terutama browser mobile seperti Chrome Android dan Safari iOS.

7️⃣ Performance Check

  • Modal terbuka dengan smooth (tidak lag)
  • Transisi antar step tidak patah-patah
  • Progress bar animation smooth (tidak skip)
  • Loading step 4 tepat 2 detik (tidak lebih, tidak kurang)
  • Scroll modal lancar tanpa lag
  • Tidak ada console error di DevTools

8️⃣ Accessibility Check

  • Tombol dapat di-focus dengan Tab keyboard
  • Modal dapat ditutup dengan tombol Escape
  • Label form terhubung dengan input (klik label = focus input)
  • Contrast warna text & background cukup (mudah dibaca)
  • Icon & emoji terlihat di semua device

📝 Expected User Flow

  1. User membuka index.html
  2. User klik tombol "Lihat Profil Kandidat"
  3. User klik kartu Kandidat 02 (Kandidat Utama)
  4. Modal Visi & Misi terbuka
  5. User klik tombol "🗳️ Simulasi Pemilihan"
  6. Modal Simulasi terbuka - Progress 0%
  7. Step 1: User isi NIK (16 digit) & Token → Klik "Lanjut" → Progress 20%
  8. Step 2: User pilih kandidat → Klik "Lanjut" → Progress 40%
  9. Step 3: User cek konfirmasi → Klik "Kirim Suara" → Progress 60%
  10. Step 4: Loading 2 detik → Auto lanjut → Progress 80%
  11. Step 5: Bukti voting muncul → Progress 100%
  12. User klik "Selesai" atau "🔄 Coba Lagi"
✅ Setelah semua test selesai:

Pastikan semua item di checklist berfungsi dengan baik. Jika ada yang error, catat dan perbaiki sebelum deploy ke Vercel.
