📊 SIMULATION FLOW
════════════════════════════════════════════════════════════════

STEP 1: Verifikasi Data Pemilih
   Input: NIK (16 digit) + Token
   Progress: 0% → 20%
   Button: [Lanjut →]
   ↓

STEP 2: Pilih Kandidat
   Input: Klik salah satu kandidat (01/02/03)
   Progress: 20% → 40%
   Button: [← Kembali] [Lanjut →]
   ↓

STEP 3: Konfirmasi Pilihan
   Display: NIK, Token, Kandidat Terpilih
   Progress: 40% → 60%
   Button: [← Kembali] [Kirim Suara 📤]
   ↓

STEP 4: Processing
   Display: Loading spinner (2 detik)
   Progress: 60% → 80%
   Auto: Lanjut ke Step 5 setelah 2 detik
   ↓

STEP 5: Berhasil!
   Display: Bukti Voting (Nomor Transaksi + Waktu)
   Progress: 80% → 100%
   Button: [Selesai] [🔄 Coba Lagi]

════════════════════════════════════════════════════════════════
🔧 TROUBLESHOOTING
════════════════════════════════════════════════════════════════

PROBLEM: Progress bar tidak bergerak
SOLUTION:
   → Cek console (F12) untuk error JavaScript
   → Pastikan script.js ter-load
   → Clear cache (Ctrl + Shift + R)

PROBLEM: Modal tidak muncul
SOLUTION:
   → Klik kandidat 02 terlebih dahulu
   → Cek apakah modal Visi & Misi terbuka dulu
   → Cek console untuk error

PROBLEM: Validasi tidak bekerja
SOLUTION:
   → NIK harus tepat 16 digit (tidak boleh lebih/kurang)
   → Token minimal 3 karakter
   → Jangan ada spasi

PROBLEM: Loading stuck di Step 4
SOLUTION:
   → Tunggu 2 detik penuh
   → Jangan klik apapun saat loading
   → Jika lebih dari 5 detik, refresh halaman
