  📖 README SINGKAT - WEBSITE PILKADES 2026
═══════════════════════════════════════════════════════

🚀 CARA CEPAT MEMULAI:
───────────────────────────────────────────────────────

1. Double-klik: MULAI-DISINI.bat
2. Itu saja! Website akan terbuka dengan benar.


📸 CARA UPLOAD FOTO KANDIDAT:
───────────────────────────────────────────────────────

1. Siapkan foto (400x400px, format JPG/PNG)
2. Rename jadi: kandidat-01.jpg, kandidat-02.jpg, kandidat-03.jpg
3. Copy ke folder: assets/images/kandidat/
4. Edit kandidat.html, ganti URL foto
5. Buka dari index.html (lewat MULAI-DISINI.bat)


⚠️  HAL PENTING YANG HARUS DIINGAT:
───────────────────────────────────────────────────────

✅ BENAR:
   - Buka MULAI-DISINI.bat
   - Buka index.html dulu
   - Gunakan tombol navigasi di website

❌ SALAH:
   - Jangan buka kandidat.html langsung!
   - Path foto tidak akan berfungsi!


🔧 KALAU ADA MASALAH:
───────────────────────────────────────────────────────

1. Baca: INFO-PENTING.txt
2. Buka: test-foto.html (untuk test foto)
3. Baca: TROUBLESHOOTING-FOTO.md (panduan lengkap)
4. Baca: QUICK-START.md (panduan cepat)


📁 FILE PENTING:
───────────────────────────────────────────────────────

⭐ MULAI-DISINI.bat        ← DOUBLE-KLIK INI!
📄 index.html              ← Halaman awal (sosialisasi)
📄 kandidat.html           ← Halaman kandidat (via tombol)
📄 INFO-PENTING.txt        ← Baca ini jika ada masalah
📄 QUICK-START.md          ← Panduan cepat
📄 README.md               ← Dokumentasi lengkap

📁 assets/images/kandidat/ ← Taruh foto di sini!


🌐 CARA DEPLOY KE ONLINE:
───────────────────────────────────────────────────────

1. Install Vercel CLI: npm install -g vercel
2. Login: vercel login
3. Deploy: vercel --prod
4. Atau upload ke vercel.com via website


💡 TIPS:
───────────────────────────────────────────────────────

- Test dulu di local sebelum deploy
- Pastikan semua foto sudah di-upload
- Update nama desa, tanggal, dan nomor WA
- Test di berbagai device (HP, tablet, laptop)
