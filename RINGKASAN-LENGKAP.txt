  🎯 FITUR WEBSITE
═══════════════════════════════════════════════════════════════

✅ HALAMAN SOSIALISASI (index.html):

1. Hero Section
   • Logo ballot box animasi
   • Judul dan subtitle
   • Call to action

2. Info Cards (4 kartu)
   • Tanggal & waktu voting
   • Platform voting (online)
   • Syarat memilih (DPT + token)
   • Jumlah kandidat (3 calon)

3. Keunggulan Voting Online
   • Praktis & cepat
   • Aman & terenkripsi
   • Real-time monitoring
   • Akses dari mana saja

4. Tata Cara Voting Online (6 langkah)
   • Terima token via SMS/WhatsApp
   • Buka link voting
   • Login dengan NIK + token
   • Pilih kandidat
   • Konfirmasi pilihan
   • Terima bukti voting

5. FAQ (6 pertanyaan)
   • Nomor HP tidak aktif?
   • Voting online aman?
   • Kapan harus voting?
   • Bisa ubah pilihan?
   • Internet lambat?
   • Bukti voting berhasil?

6. Warning Boxes
   • Pastikan nomor HP aktif
   • Jaga kerahasiaan token
   • Voting hanya 1 kali

7. CTA Button
   • "Lihat Profil Kandidat"

8. Contact
   • Link WhatsApp Tim Teknis

───────────────────────────────────────────────────────────────

✅ HALAMAN KANDIDAT (kandidat.html):

1. Navigation Bar
   • Tombol "Kembali ke Beranda"

2. Hero Section
   • Judul "Profil Kandidat Kepala Desa"

3. Grid Kandidat (3 kartu)
   
   KANDIDAT 01 & 03 (Lawan):
   • Foto grayscale/siluet
   • Warna redup
   • Non-interaktif
   
   KANDIDAT 02 (Kandidat Utama):
   • Foto asli berwarna
   • Border emas beranimasi
   • Label "Klik untuk Lihat Visi & Misi"
   • Badge "Berpengalaman" & "Profesional"
   • Hover effect dengan overlay
   • Klik untuk buka modal

4. Modal Visi & Misi (Pop-up)
   
   Berisi:
   • Visi lengkap
   • 5 poin Misi
   • 3 Program Kerja Unggulan:
     - Bantuan Modal Usaha Produktif
     - Perbaikan Jalan dan Saluran Air
     - Digitalisasi Layanan Desa
   
   Fitur:
   • Tombol close (X)
   • Klik overlay untuk tutup
   • Tombol "Tutup" di footer
   • Scrollable content

5. WhatsApp Floating Button
   • Fixed di kanan bawah
   • Link ke Tim Sukses
   • Responsive (jadi circle di mobile)

Primary: Biru Tua (#1e3a8a) - Kepemimpinan & wibawa

✅ TYPOGRAPHY:

Font: System font stack (Segoe UI, Roboto, sans-serif)
Size: Responsive (48px → 32px → 28px → 25px)

✅ ANIMASI:

• Border glow pada kandidat utama
• Fade-in saat scroll
• Hover effects
• Modal slide-up
• Background shapes floating
• Pulse effect logo

✅ RESPONSIVE DESIGN:

Breakpoints:
• Desktop: > 768px
• Tablet: 481-768px
• Mobile: 361-480px
• Mobile Small: ≤ 360px

Touch Optimizations:
• Tap target minimal 44x44px
• Active states untuk feedback
• No hover effects di touch device
• Swipe-friendly modal

  🚀 CARA MENGGUNAKAN

STEP 1: PERSIAPAN FOTO

1. Siapkan 3 foto kandidat:
   • kandidat-01.jpg (400x400px)
   • kandidat-02.jpg (400x400px)
   • kandidat-03.jpg (400x400px)

2. Upload ke: assets/images/kandidat/

3. Edit kandidat.html:
   Ganti URL foto dari placeholder ke:
   assets/images/kandidat/kandidat-02.jpg

───────────────────────────────────────────────────────────────

STEP 2: EDIT KONTEN

1. Nama Desa:
   File: index.html & kandidat.html
   Ganti "Sukamaju" dengan nama desa Anda

2. Tanggal Voting:
   File: index.html
   Ganti "15 Maret 2026"

3. Nomor WhatsApp:
   File: index.html & kandidat.html
   Ganti "6281234567890"

4. Nama Kandidat:
   File: kandidat.html
   Ganti "Nama Kandidat Utama"

5. Visi & Misi:
   File: kandidat.html
   Edit di dalam modal

───────────────────────────────────────────────────────────────

STEP 3: TEST LOKAL

1. Double-klik: MULAI-DISINI.bat
2. Website akan terbuka di browser
3. Test semua fitur:
   • Navigasi
   • Modal
   • Foto kandidat
   • WhatsApp button
4. Test responsive: TEST-RESPONSIVE.html

───────────────────────────────────────────────────────────────

STEP 4: DEPLOY KE VERCEL

1. Double-klik: PERSIAPAN-DEPLOY.bat
2. Ikuti checklist
3. Pilih metode deploy:
   
   A. DRAG & DROP (Tercepat):
      • Buka vercel.com
      • Sign up
      • Drag folder ke upload area
      • Deploy!
   
   B. VIA GITHUB (Auto-update):
      • Push ke GitHub
      • Connect Vercel
      • Auto deploy
   
   C. VIA CLI (Developer):
      • npm install -g vercel
      • vercel login
      • vercel --prod

───────────────────────────────────────────────────────────────

STEP 5: SHARE LINK

1. Copy URL: https://your-project.vercel.app
2. Share via:
   • WhatsApp Group
   • Facebook
   • Instagram
   • QR Code untuk poster
