Cara membuka website Pilkades dengan benar

🚫 Jangan Buka kandidat.html Langsung!

Jika Anda membuka file kandidat.html secara langsung dari File Explorer, foto kandidat dan navigasi tidak akan berfungsi dengan benar.

✅ Cara yang Benar:

1
Double-klik file MULAI-DISINI.bat atau buka index.html
2
Scroll ke bawah di halaman sosialisasi
3
Klik tombol besar "Lihat Profil Kandidat"
4
Anda akan otomatis pindah ke halaman kandidat dengan path yang benar!

📂 Alur Website:

index.html
(Sosialisasi)
→
kandidat.html
(Profil Kandidat)
→
Kembali ke index.html

💡 Mengapa Harus Begini?

  • Path foto mengikuti struktur dari index.html
  • Navigasi website berjalan dengan baik
  • Animasi dan transisi smooth
  • Browser dapat menemukan semua file dengan benar
