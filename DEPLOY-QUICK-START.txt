📌 METODE TERCEPAT: DRAG & DROP

┌─────────────────────────────────────────────────────────────┐
│  STEP 1: PERSIAPAN                                          │
└─────────────────────────────────────────────────────────────┘

✅ Double-klik: PERSIAPAN-DEPLOY.bat
   (Akan auto-check semua yang perlu disiapkan)


┌─────────────────────────────────────────────────────────────┐
│  STEP 2: BUKA VERCEL                                        │
└─────────────────────────────────────────────────────────────┘

1. Buka browser (Chrome/Firefox/Edge)
2. Ketik: vercel.com
3. Klik "Sign Up" (pojok kanan atas)


┌─────────────────────────────────────────────────────────────┐
│  STEP 3: BUAT AKUN                                          │
└─────────────────────────────────────────────────────────────┘

Pilih salah satu:
• Continue with GitHub (Recommended)
• Continue with GitLab
• Continue with Email


┌─────────────────────────────────────────────────────────────┐
│  STEP 4: DEPLOY                                             │
└─────────────────────────────────────────────────────────────┘

1. Setelah login, klik "Add New..." → "Project"

2. Scroll ke bawah, cari tulisan:
   "Or, deploy a Template or a new project without Git"

3. Anda akan lihat kotak besar:
   
   ┌────────────────────────────────────┐
   │                                    │
   │   📁 Drop your project folder      │
   │         here to deploy             │
   │                                    │
   │       or click to browse           │
   │                                    │
   └────────────────────────────────────┘

4. DRAG folder "sosialisasi pilkades" ke kotak ini

   ATAU

   Klik kotak → Pilih folder "sosialisasi pilkades"


┌─────────────────────────────────────────────────────────────┐
│  STEP 5: KONFIGURASI (OPSIONAL)                            │
└─────────────────────────────────────────────────────────────┘

Setelah upload, Anda lihat form:

• Project Name: pilkades-sukamaju-2026 (bisa diganti)
• Framework Preset: Other (biarkan)
• Root Directory: ./ (biarkan)

Klik tombol besar: "DEPLOY"


┌─────────────────────────────────────────────────────────────┐
│  STEP 6: TUNGGU                                             │
└─────────────────────────────────────────────────────────────┘

Vercel akan proses deployment:

• Building... (30 detik)
• Deploying... (30 detik)
• Success! 🎉


┌─────────────────────────────────────────────────────────────┐
│  STEP 7: SELESAI! 🎉                                        │
└─────────────────────────────────────────────────────────────┘

Website SUDAH LIVE!

URL: https://pilkades-sukamaju-2026.vercel.app
     (URL akan berbeda tergantung project name Anda)

Klik link untuk membuka website!

  🔄 CARA UPDATE WEBSITE SETELAH DEPLOY
═══════════════════════════════════════════════════════════════

Jika ada perubahan (edit konten, ganti foto, dll):

CARA 1: REDEPLOY MANUAL

1. Login ke vercel.com
2. Pilih project Anda
3. Klik "Deployments"
4. Klik "Redeploy" → Upload folder baru

CARA 2: VIA CLI (JIKA SUDAH SETUP)

1. Edit file di local
2. Buka Command Prompt di folder project
3. Jalankan: vercel --prod
4. Done! Auto-update


═══════════════════════════════════════════════════════════════
  ❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

MASALAH: Foto tidak muncul setelah deploy

SOLUSI:
• Cek folder: assets/images/kandidat/ ada?
• Cek nama file: kandidat-01.jpg (huruf kecil)
• Cek path di HTML: assets/images/kandidat/kandidat-01.jpg
• Redeploy

─────────────────────────────────────────────────────────────

MASALAH: Website lambat loading

SOLUSI:
• Compress foto (< 300KB per foto)
• Gunakan TinyPNG.com
• Redeploy

─────────────────────────────────────────────────────────────

MASALAH: Deployment failed

SOLUSI:
• Cek log error di Vercel dashboard
• Pastikan vercel.json ada
• Coba deploy ulang
