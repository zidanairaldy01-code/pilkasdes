# 📁 Folder Logo & Gambar Umum

Folder ini untuk menyimpan logo, banner, dan gambar umum website.

## 📌 File yang Bisa Disimpan di Sini:

- `logo-desa.png` - Logo Desa Sukamaju
- `logo-pilkades.png` - Logo khusus Pilkades 2026
- `banner.jpg` - Banner header website
- `background.jpg` - Gambar background (jika diperlukan)

## 🎨 Format Rekomendasi:

- Logo: PNG dengan background transparan
- Banner: JPG/PNG dengan ukuran 1920x600px
- Ukuran file: Maksimal 500KB

---

**Tip**: Gunakan format PNG untuk logo agar background transparan!
